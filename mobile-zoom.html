缩放基准：两指中心 · 上限 4× · 双击切换 1× / 2× 就绪

为什么"缩放不跳"

  • 手指按下时记住两指初始距离 d0、初始缩放 s0、初始位移 t0 与两指中点 p0；
  • 中途只算比例 s = s0 × d1 / d0，不再累乘，所以不会越缩越飘；
  • 把中点 p0 换算成图片内部坐标 c = (p0 − t0) / s0，再用 t = p1 − c × s 反推位移，保证"手指底下那张图的那一点"始终不动；
  • 松手时把位移夹到边界内（1× 时直接归零），所以不会把图拖出容器。
